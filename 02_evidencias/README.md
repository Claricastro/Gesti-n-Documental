# Ruta Joven San Gabriel
## Orientación para la Empleabilidad y el Emprendimiento

Proyecto académico de Herramientas Digitales para la Gestión y Monitoreo de Proyectos, 2026-2.

**Código del equipo:** pendiente de confirmar.

## Problema

Los jóvenes de 18 a 28 años de San Gabriel enfrentan dificultades para acceder al empleo y al emprendimiento, relacionadas con falta de experiencia, necesidades de formación y desconocimiento de los servicios de apoyo.

La base de 479 respuestas sintéticas permite explorar estas barreras como escenario académico. Sus resultados requieren contrastación con evidencia local real.

## Alternativa de intervención

Diseñar un servicio piloto de orientación juvenil con cuatro módulos: diagnóstico individual, empleabilidad, emprendimiento y remisión a la oferta institucional.

## Descripción operativa y alcance

El proyecto comprende la planeación, organización y ejecución simulada del servicio para jóvenes de sectores urbanos consolidados, periféricos y rurales.

Se prepararán materiales y protocolos, se simularán la convocatoria y la inscripción, se definirán itinerarios de orientación y se documentarán las remisiones, incidencias y resultados de seguimiento.

La duración, las metas numéricas y los acuerdos institucionales están pendientes de validación.
